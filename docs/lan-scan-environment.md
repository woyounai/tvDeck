# 局域网环境与手动扫描

设备主页创建时立即启动被动 NWPathMonitor，分别检查默认路径、Wi-Fi 和有线网络。检测中、无网络或仅蜂窝／VPN 时禁用首页与工具栏扫描入口，显示对应说明；启动与恢复网络都不自动扫描。允许无互联网的 Wi-Fi／有线局域网，不以访问外网成功作为条件。

DeviceDiscovery.start 本身也检查同一个门禁，不能绕过 UI 启动 Bonjour 或 IPv4 探测。失去局域网时取消当前扫描、清理结果，并忽略已取消浏览器的延迟回调。IPv4 候选仅来自被动路径报告的 Wi-Fi／有线接口，排除蜂窝和 VPN 接口。

被动路径满足不代表 iOS 已授予本地网络权限，也不能识别访客网络隔离或证明电视同网段。权限申请仍在用户明确手动扫描时由系统触发；扫描本身保留权限／发现错误提示。手动 IP 连接与保存设备不受扫描门禁限制。

运行 tests/run-lan-tests.sh 验证启动检测、蜂窝／VPN、离线、Wi-Fi、有线与网络恢复策略；完整 App 双架构构建验证 Network/SwiftUI 集成。真机断网／换网与权限拒绝仍需复测。
