# Cyberpunk 赛博朋克主题

## 视觉

- 暗夜蓝底（深色基底约 #090B16）、青色强调与紫红光晕。
- 32 点细网格，静态 Canvas 绘制，不使用持续动画或显示刷新定时器。
- 深色面板、18 点圆角、青紫渐变细边框和低强度光晕；保留原生字体与系统动态字号。
- 终端保持黑底薄荷色文字，命令输入栏恢复原生可读前景色。
- 普通控制用高对比青色/紫色，实心主按钮使用深紫底，避免白字叠在亮青色上。

首次使用此配置默认选择赛博朋克；设置 → 视觉主题可切回经典。视觉主题与浅色/深色/跟随系统独立：浅色版本改用淡紫白底和深紫文字，不强行改变用户外观设置。

## 实现

VisualTheme.swift 定义主题存储和环境值、共享背景与网格。DesignSystem.swift 提供自适应调色板及面板边框。主要页面和操作弹框使用共享背景修饰器，切换主题不通过重新创建 RootView 实现，不重置导航或 ADB 会话。

覆盖设备主页、文件、应用、遥控、工具、设置、遥控中心和键盘/鼠标操作弹框；视频画面仍保持黑色背景，终端仍保持黑底。经典主题可恢复原有蓝色调。

## 验证边界

iOS arm64 模拟器无签名构建通过，既有逻辑和编解码检查按本次交付执行。尚未在 iPhone 上截图验收，需检查真实 iOS 上的浅/深色切换、动态字号、横屏以及弹框过渡。

顶部覆盖：赛博主题隐藏导航栏自带的实色背景，让页面背景延伸到导航标题和状态栏；根视图也提供全屏背景，覆盖连接页面切换时的安全区。底部标签栏保留实色底以确保可读性。真实 iPhone 的顶部覆盖仍需截图验收。
