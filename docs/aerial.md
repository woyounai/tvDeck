# Aerial 桌面联动

[简体中文](aerial.md) · [English](aerial.en.md)

[返回项目总览](../README.md)

iOS 与安卓客户端的首页、工具页均提供「扫码连接 Aerial」。扫描电视 Aerial 的手机管理二维码后，iOS 在内置 Safari 页面打开，安卓使用系统浏览器；直接使用 Aerial 官方网页管理桌面、壁纸和屏保，无需先建立 ADB 连接。两端需位于同一可信局域网，Aerial 需正在运行。管理二维码与 ADB 连接／配对二维码分开识别，不保存管理令牌。

ADB 连接成功后会自动检测 Aerial 安装状态。工具页提供一键安装／升级，下载官方最新稳定版并校验 SHA-256、大小、包名和版本号；升级保留 Standard／Guard／Lite 类型，不降级、不自动卸载。安装后按官方 Windows 第 3、6 步授权并启动，展示逐条结果；不主动设置默认桌面、屏保或保持 ADB 常开。首次安装可选 Standard 或 Guard，旧 Android 自动选 Lite。

手机安装流程：手机和电视连接同一 Wi-Fi，电视打开 ADB 后在 TVDeck 连接 `<电视IP>:5555`（Android 11+ 无线调试按电视提示先配对），在电视选择「始终允许」。工具页选择安装 Aerial，默认 Standard，固件拒绝时可重试 Guard；安装后自动授权并启动，也可单独点击「授权并启动」。授权命令执行完成、App 启动成功与桌面接管成功分别判断，此流程不宣称已完成桌面接管验收。
